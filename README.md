## 👋 About me

I build AI systems end to end: train and fine-tune the model, make it fast to serve, wrap it in a platform other teams can use, and ship the product around it. I also use AI coding agents as part of the engineering process itself, with specs, gates and tests that keep their output correct at scale.

- 🤖 **AI / ML** — fine-tuning (LoRA, QLoRA, QAT), evaluation, RAG, document understanding
- ⚙️ **MLOps & AI platform** — training pipelines, model registry and gating, serving, GPU performance tuning
- 🧠 **Agent engineering** — agentic software development lifecycle, skills, sub-agents, hooks, MCP
- 🌐 **Full-stack** — Go gRPC services, FastAPI, Next.js, Kafka, data pipelines
